# Third place

目的に合ったカフェを東京の駅ごとに探せる地図＋記事サイト。「きょうはなにする？」に合わせて行き先を提案する相棒がコンセプト。家でも職場でもない「第三の居場所」を、目的に合わせてAIの相棒が提案する。サイト名は `src/lib/brand.ts` だけで変えられる。将来は利用者がお気に入りを投稿・共有するSNSに広げる。

## 目的と評価軸

| 目的 | URL | スコア | 3つの軸（重み） |
|---|---|---|---|
| カフェ作業 | /work/<駅>/ | 作業スコア | Wi-Fi（35%）・電源（35%）・作業しやすさ（30%） |
| 犬と行く | /dog/<駅>/ | わんこスコア | 犬の入店：店内OK/テラスのみ（50%）・犬ごはん（20%）・駐車場（30%） |
| 子どもと行く | 準備中 | | |
| 誕生会をひらく | 準備中 | | |

目的の追加は `src/lib/purposes.ts` に1件足すだけで、駅ページ・フィルター・スコア・地図のピンが揃う。

## いまの状態（試作 v0.2）

- トップ（目的→駅）／目的×駅ページ（地図＋条件で絞り込み）／店舗ページ／記事／投稿フォーム（送信は未接続）
- 店舗データは **すべて見本**（`src/data/spots.ts`）。店名は架空で、実在の店舗とは関係ない
- 最初の10駅：渋谷・新宿・池袋・東京・品川・恵比寿・中目黒・吉祥寺・秋葉原・横浜

## 技術構成

| 役割 | 使うもの | 費用 |
|---|---|---|
| フレームワーク | Next.js 15（App Router、全ページ静的生成） | 0円 |
| ホスティング | Vercel 無料枠（Cloudflare Pages でも可） | 0円 |
| 地図 | MapLibre GL ＋ OpenFreeMap のOSMタイル（APIキー不要） | 0円 |
| 店舗データ | 当面はリポジトリ内のTSファイル → 投稿機能を入れる段階で Supabase（PostGIS） | 0円〜 |
| フォント | Dela Gothic One／Zen Kaku Gothic New／IBM Plex Mono（next/font で自前配信） | 0円 |

地図タイルが読み込めないときは、駅を中心に徒歩3・6・9分の同心円を描く簡易地図に自動で切り替わる。

## 開発

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # 本番ビルド
npm run export     # 静的HTMLを out/ に書き出す
npm run import:osm # OSMから各駅のカフェ候補を data/osm/ に取得（調査用）
```

環境変数

- `NEXT_PUBLIC_SITE_URL`：本番のURL（canonical・サイトマップ用）
- `NEXT_PUBLIC_ALLOW_INDEX=1`：検索エンジンへの掲載を許可（試作中は未設定＝noindex）
- `NEXT_PUBLIC_GA_ID`：GA4 の測定ID（G-から始まる）。設定すると全ページで計測
- `NEXT_PUBLIC_GSC_VERIFICATION`：Search Console の「HTMLタグ」確認コード（content の値）。DNS で確認する場合は不要

## データの方針

- 食べログ・Googleマップの店舗情報・口コミ・写真は転載しない
- 位置と店名の候補は OpenStreetMap（ODbL、クレジット表記必須）
- 電源席の数・位置、時間制限などは現地調査と投稿で埋め、店ごとに「最終確認日」を出す
- 見本データ（`source: "sample"`）はサイトマップと構造化データから除外している

## デザインの考え方

- 編集的なトーン：白・青・黄色に濃紺の線。見出しは太い明朝（しっぽり明朝B1）、数字と英字は Fraunces、本文はゴシック
- 人物イラスト：[Open Peeps](https://www.openpeeps.com/)（Pablo Stanley、CC0：商用・改変可・クレジット不要）を react-peeps（MIT）で描画。犬・テーブル・東京タワーなどの小物は自作SVG（`src/components/People.tsx`, `HeroStage.tsx`, `PurposeArt.tsx`）
- 東京らしさ：駅カードは駅名標（かな・漢字・ローマ字＋路線色の帯）
- 色は意味にだけ使う：目的ごとの色（作業＝青、犬＝オレンジ、子連れ＝緑、誕生会＝ピンク）と、軸ごとの色
- どの店も同じ「スコア＋3本のバー」で比べられる
- ライト／ダーク両対応、スマホでは地図が上・一覧が下
